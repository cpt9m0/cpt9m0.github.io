## Teaching

I am a Graduate Research and Teaching Assistant at Texas A&M University, Department of Computer Science and Engineering.

<div class="section-card">
<h3>Graduate Courses</h3>

<h4>CSCE 611 - Graduate Operating Systems</h4>
<p>Advanced operating systems concepts including process management, memory management, file systems, and distributed systems. Graduate-level exploration of OS design and implementation.</p>

<h4>CSCE 413 - Software Security</h4>
<p>Fundamentals of software security including secure coding practices, vulnerability analysis, exploit development, and defensive programming. Covers topics such as buffer overflows, format string vulnerabilities, and control-flow integrity.</p>
</div>

<div class="section-card">
<h3>Undergraduate Courses</h3>

<h4>CSCE 482/483 - Senior Capstone Design</h4>
<p>Senior-level project course where students design and implement a significant software or hardware project. I mentor student teams on project planning, architecture, implementation, and documentation.</p>

<h4>CSCE 410 - Operating Systems</h4>
<p>Introduction to operating system concepts including processes, threads, synchronization, memory management, and file systems. Includes programming projects in C and Java.</p>

<h4>CSCE 313 - Introduction to Computer Systems</h4>
<p>Introduction to computer systems from a programmer's perspective. Topics include data representation, assembly language, memory hierarchy, linking, and exceptional control flow.</p>
</div>
