# Hermes Backup

Hermes Backup is a private, single-user automation operated by Ali Ayati. It uses the Google Drive API to store and maintain encrypted-access backup files in Ali's own Google Drive account.

The tool runs on Ali's own server and is not offered to the public. It uses Google authorization only for the account that owns and operates the backup. Its Drive access is used to:

- upload backup snapshots;
- verify uploaded files;
- list backup snapshots; and
- remove expired snapshots according to the configured retention policy.

Hermes Backup does not provide third-party access to Google accounts or data.

For details about data handling, see the [Hermes Backup Privacy Policy](/hermes-backup/privacy/).
