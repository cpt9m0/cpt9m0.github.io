# Privacy Policy for Hermes Backup

**Effective date:** November 9, 2026

Hermes Backup is a private, single-user backup automation operated by Ali Ayati. It uses the Google Drive API only on behalf of the Google account that owns and operates the backup.

## Google data accessed

Hermes Backup may create, list, read, verify, and delete files and folders in Google Drive. Although Google authorization grants Drive access, the application is configured to operate only on its designated backup folder and uses that access to upload snapshots, verify uploads, list existing snapshots, and enforce backup retention.

## How data is handled

- The application runs on the operator's own server.
- API requests are made directly between that server and Google's services.
- Backup files are stored in the operator's Google Drive account.
- OAuth credentials are stored locally on the operator's server with restricted filesystem permissions.
- Google user data is not sold, rented, shared with advertisers, or used for advertising.
- Google user data is not used to train generalized artificial-intelligence or machine-learning models.
- The application does not collect analytics or telemetry about Google Drive data.

## Data sharing

Hermes Backup does not disclose Google user data to third parties. Data may be disclosed only when required by law or necessary to protect the security of the operator's systems.

## Data retention and deletion

Backup snapshots are retained according to the operator's configured retention policy. Expired snapshots are deleted automatically. The operator can stop the application and revoke its Google access at any time through Google Account security settings.

## Security

Reasonable technical measures are used to protect credentials and backups, including restricted local file permissions and access limited to the operator. No method of storage or transmission is guaranteed to be completely secure.

## Changes

This policy may be updated if the application's data practices change. The effective date above identifies the latest revision.
